# DREAM Integrity & Outcome Lens

Independent civic-tech research project for deterministic evidence lineage, consistency checking, and outcome assurance over public Ukrainian reconstruction and public-investment data.

> **Status:** repository initialized. The first implementation is being developed under a reviewable feature branch.

This project is **not** an official component of DREAM and does not infer corruption, fraud, criminality, or misconduct from anomalies. Findings are evidence-backed consistency states intended for human review.

Authoritative source systems remain authoritative for their own records; this project records observations, relationships, provenance, and deterministic rule results.

## Languages

Project-facing documentation and reporting are intended for Ukrainian and English.
